# Binary evidence upload guide

The v1.2 repository ZIP holds the eight binary exhibits, PNG/PDF documents, and the prebuilt student archive. From GitHub choose **Add file → Upload files** and upload those files to their respective directories; retain filenames and file bytes. Alternatively publish the student ZIP as a release asset, update README with its verified link, and host all evidence via that ZIP. Verify SHA-256 and the signed witness afterward. Do not upload any instructor private files.
